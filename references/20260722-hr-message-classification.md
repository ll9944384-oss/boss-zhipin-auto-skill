# HR 消息分类规则（2026-07-22 现场验证）

## 从 page text 区分消息类型

BSOS 直聘聊天页的 `document.body.innerText` 中，所有对话**按时间倒序**排列在一个列表中（类似邮箱收件箱）。每条对话的文本格式：

```
时间
HR姓名公司职位
消息预览

时间
HR姓名公司职位
消息预览
```

### 启发式分类

| 特征 | 类型 | 示例 |
|------|------|------|
| 无前缀，内容像打招呼/提问 | **HR主动消息 — 需处理** | `"14:17\n<HR>女士COMPANY_3hr\nhello现在是离职状态吗？"` |
| 无前缀，内容含"不够匹配""不符合""不合适" | **系统拒绝** — 无需处理 | `"感谢您的关注，感觉您的个人经验与我们招聘要求不太符合"` |
| 带 `[已读]` 前缀 | **自己已发送的消息** — 跳过 | `"[已读]\n这是我的作品集，百度网盘链接：..."` |
| 带 `[送达]` 前缀 | **自己刚发送的消息** — 跳过 | `"[送达]\n这是我的作品集，百度网盘链接：..."` |
| 带 `[图片]` 内容 | HR 发了图片（JD截图等）— 按上下文判断 | 能否回复取决于是否特定提问 |
| 含"无责保底""酒店住宿""保姆"等 | **广告/群发** — 跳过 | |

### 2026-07-22 实际案例

```
15:20
<HR>女士COMPANY_2招聘者
你好，在推荐里面看到你的简历...在找短视频拍摄剪辑...
→ HR主动消息，但短视频方向 → 排除

14:17
<HR>女士COMPANY_3hr
hello现在是离职状态吗？
→ HR主动消息 ✅ 提问离职状态 → 应回复

13:31

你好 我们公司是做mcn达人孵化...
→ HR主动消息，但MCN达人孵化 → 排除

请问在考虑新的工作机会吗？
→ HR主动消息 ✅ 问机会 → 应回复
```

## 处理流程

1. 解析 page text，按时间排序提取所有对话
2. 过滤：
   - 跳过 `[已读]`、`[送达]`、`[图片]` 前缀（不是HR新消息）
   - 跳过含"不够匹配""不符合"的拒绝通知
   - 跳过含排除关键词的对话（见用户画像排除规则）
3. 从剩余对话中取**时间最新的一条**
4. 判断回复类型（问离职/问机会/问技能/约面试/要简历等）
5. 生成回复 → 发送 → 停止（等下次cron）
