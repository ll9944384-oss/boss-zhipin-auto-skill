# Cron HR消息检查：document.body.innerText 解析法

## 日期
2026-07-23 会话验证

## 背景

在无法通过 JS click 或 pyautogui 打开具体对话的情况下（Vue SPA 事件屏障），
通过读取 `document.body.innerText` 一次性获取所有对话内容，进行文本解析。

## 方法

```python
from scripts.safari_boss_runner import json_js, run_bridge

# 1. 导航到聊天页
run_bridge('navigate', 'https://www.zhipin.com/web/geek/chat')

# 2. 读取全量文本
js = 'return document.body.innerText || "";'
data = json_js(js)
text = data.get('result', '')
```

## 对话识别规则

解析 `document.body.innerText` 中的对话结构：

### HR 发来的消息（需要处理）
格式：
```
[时间]
[HR名字+头衔]
[消息内容]
```
特征：消息内容前 **没有** `[已读]` 或 `[送达]` 标记。

### 我方发送的消息（已处理）
格式：
```
[时间]
[HR名字+头衔]
[已读] 或 [送达]
[消息内容]
```
特征：消息内容前有 `[已读]`（HR已读）或 `[送达]`（仅送达）标记。

### 系统通知（跳过）
```
感谢您的关注，暂时与该职位不够匹配...
```
特征：无 `[已读]/[送达]` 标记，但内容为拒绝/系统通知。

## 处理规则（按优先级）

1. **跳过**：纯短视频/抖音/快手方向、AI抽卡师/经纪人、MCN达人孵化、品牌推广广告
2. **跳过**：拒绝通知（"不匹配"、"不合适"）
3. **回复**：HR要简历 → 同意并发送附件简历 `YOUR_NAME.pdf`
4. **回复**：HR提问/邀请 → 友好回复，附作品集链接
5. **最后考虑**：短剧/AIGC方向

## 与 Vue 组件访问的对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| `document.body.innerText` | 简单可靠，无需理解 Vue 结构 | 无法区分已读/未读状态；无法直接回复 |
| Vue 组件 `__vue__` | 可精确区分未读、lastIsSelf | 有时不可用；依赖内部 API |
| 结构化选择器 `.friend-content-warp` | 可提取结构化数据 | 选择器可能随版本变化 |
