# 2026-07-13 HR回复场景：复合问答+面试邀请

## 场景描述

用户给HR发问"咱们这招的是纯剪辑岗位还是什么"，HR回复"拍剪写 主要是以拍和剪辑为主"。同时，
该对话中HR此前已发出面试邀请"明天上午10点面试方便吗？"，用户尚未回复此面试邀请。

## 对话历史分析

```
HR: 明天上午10点面试方便吗？         ← 面试邀请（用户未回复）
用户: 咱们这招的是纯剪辑岗位还是什么   ← 用户先问了另一个问题
HR: 拍剪写 主要是以拍和剪辑为主       ← HR回答了用户问题（最新消息）
```

## 关键判断

- HR的最新消息（"主要是以拍和剪辑为主"）是对用户提问的答复
- 但用户仍有**未回复的面试邀请**需要处理
- 回复时需同时覆盖 **确认HR的回答** + **补答面试邀请** + **附作品集链接**

## 回复内容

```
好的，了解了！主要是拍剪写一体的岗位，我可以胜任，有拍摄和剪辑经验。
今天上午10点面试方便的。
这是我的作品集：https://pan.baidu.com/s/<YOUR_SHARE_ID> 提取码：<CODE>
```

## 执行步骤（已验证）

1. 用 `mousedown+mouseup+click` 事件序列打开对话
   - 直接 `el.click()` 可能不触发 Vue SPA 路由
   - 需等待2-3秒让右侧面板渲染
2. 读取 `.chat-conversation` 的 innerText 查看完整对话历史
3. 确认 HR 最新消息内容，同时检查是否遗漏了之前的面试邀请
4. 用 `send_text_value(msg)` 发送回复（内含 Enter 键 + pyautogui 备选点击）
5. 额外调用 `click-send`（保险措施）
6. 用 `verify-message` 验证回复内容出现在最近消息中

## 时间上下文判断规则

| 面试时间 | 当前时间 | 回复策略 |
|----------|----------|----------|
| "明天上午10点" | 当天凌晨02:00-03:00（同一天的上午） | "今天上午10点方便的" |
| "明天上午10点" | 当天下午/晚上（已错过） | "抱歉错过了，能否重新约时间？" |
| "方便来面试吗"（无具体时间） | 任意 | "请问什么时间方便？" |
